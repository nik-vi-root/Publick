CSS для текста

  • color: задает цвет текста
  • font-size: размер шрифта
  • font-weight: толщина (жирность)
  • text-align: выравнивание текста
  • line-height: межстрочный интервал
  • text-transform: преобразование регистра (например, все заглавные)
